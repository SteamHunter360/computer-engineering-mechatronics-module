# Exercise 2 — Input/Output Specification

## Triangle Area Calculator

| Variable       | Data Type | Input/Output | Description                              |
| -------------- | --------- | ------------ | ---------------------------------------- |
| a              | double    | Input        | First side length                        |
| b              | double    | Input        | Second side length                       |
| c              | double    | Input        | Third side length                        |
| s              | double    | Internal     | Semi-perimeter: (a+b+c)/2                |
| Area           | double    | Output       | Area calculated using Heron's formula    |
| Result message | Text      | Output       | Invalid side lengths or invalid triangle |
