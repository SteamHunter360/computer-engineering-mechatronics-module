# Exercise 1 — Input/Output Specification

## Quadratic and Linear Equation Solver

| Variable       | Data Type | Input/Output | Description                        |
| -------------- | --------- | ------------ | ---------------------------------- |
| a              | double    | Input        | Coefficient of x²                  |
| b              | double    | Input        | Coefficient of x                   |
| c              | double    | Input        | Constant coefficient               |
| D              | double    | Internal     | Discriminant: b² - 4ac             |
| x              | double    | Output       | Single real solution               |
| x1             | double    | Output       | First real root                    |
| x2             | double    | Output       | Second real root                   |
| Result message | Text      | Output       | Solution category or error message |
